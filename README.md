# C++ Project Template
C++ library and executable project template.

1. Replace all `TODO`'s with the name of your project.
2. Set up [CMakeLists.txt](CMakeLists.txt) and the `install-dep` scripts with your dependencies.
3. Start development!

int main(int argc, char *argv[]) {

}
